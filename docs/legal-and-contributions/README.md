# Legal and contribution records

This folder is the single index for LEO Sentinel's legal, attribution, and
contribution records:

- [Attribution](ATTRIBUTION.md) distinguishes the preserved visualization
  engine from the August challenge work.
- [Contributions](CONTRIBUTIONS.md) records the submission maintainer and the
  work added for the challenge.
- [License](LICENSE.md) points to the canonical MIT license at the repository
  root.

The root `LICENSE` file is intentionally retained because GitHub, dependency
scanners, and source-package tooling expect the canonical license there. The
original Git history is also retained as the authoritative provenance record.
