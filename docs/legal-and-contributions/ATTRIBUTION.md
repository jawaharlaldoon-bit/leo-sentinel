# Attribution

LEO Sentinel is an in-place hackathon extension of the MIT-licensed
`starlink-viz` project. Its original repository relationship and complete
authorship record are preserved in Git history.

The existing visualization, orbital propagation, Space and Sky views, Fleet
analytics, dish telemetry, WebSocket transport, ground-station catalog, ISL
routing, Docker deployment, tests, and documentation remain covered by the
original [MIT license](../../LICENSE).

The August challenge work adds the LEO Sentinel name, deterministic resilience
scenarios, the Mission Ops interface, Granite Time Series integration, grounded
Granite mission briefs, cost guardrails, AI-specific tests, and submission
documentation. Keeping the original history lets judges distinguish the
preserved engine from the challenge additions.

Starlink and SpaceX are trademarks of Space Exploration Technologies Corp.
This project is independent, unofficial, and uses public data for educational
and decision-support demonstrations.
